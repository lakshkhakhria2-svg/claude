# LK Media: startup web design portfolio

**Live:** https://lk-media.netlify.app/ (Netlify Drop; redeploy by dragging a fresh build folder onto the site's Deploys tab)

The LK Media agency site plus three concept startup sites to use as portfolio pieces on Contra and Clutch.
Every design system comes from the **UI UX Pro Max** skill (`.claude/skills/ui-ux-pro-max/`).

| Page | Path | Skill design system |
|---|---|---|
| Agency / portfolio | `index.html` | `design-system/lk-media/` (Motion-Driven · Portfolio Grid · Archivo + Space Grotesk) |
| Cadence (SaaS) | `work/cadence/` | `design-system/cadence/` (Micro-interactions · Personalised landing · Plus Jakarta Sans) |
| Northvault (fintech) | `work/northvault/` | `design-system/northvault/` (Dark Mode OLED · Hero + Testimonials + CTA · IBM Plex Sans) |
| Brightwater (local service) | `work/brightwater/` | `design-system/brightwater/` (Soft UI Evolution · Hero + Testimonials + CTA · Lexend + Source Sans 3) |

Each `design-system/<project>/MASTER.md` was generated by the skill. `pages/home.md` records where
the skill's own colour picks failed its 4.5:1 contrast rule and what was used instead.

Lighthouse (mobile, gzip like Netlify): performance 94 / 100 / 99 / 100 (agency / Cadence / Northvault / Brightwater),
accessibility, best practices and SEO 100 on all four. The agency's score includes its intro sequence.

## Motion

All animation lives in `assets/motion.js` (shared kit, driven by `data-*` attributes) plus a small inline
script per page. Libraries are self-hosted in `assets/vendor/` (GSAP 3 core + ScrollTrigger + SplitText +
ScrambleText, and Lenis), fonts in `assets/fonts/`. Everything switches off for visitors who prefer reduced
motion (or press the "Motion: on" button in the footer), and no content is hidden if the scripts fail.

## Develop

```bash
npm install
npm run dev     # rebuilds assets/styles.css as you edit
npm run build   # minified production CSS (commit the result)
```

The pages are plain static HTML. `assets/styles.css` is committed, so any static host works with no build step.

## Deploy (free)

- **GitHub Pages:** go to repo Settings → Pages → Deploy from branch → pick the branch and `/ (root)`.
  The site goes live at `https://lakshkhakhria2-svg.github.io/claude/` (`.nojekyll` makes Pages serve the files as-is).
- **Netlify:** import the repo. `netlify.toml` already publishes only the website files (to `dist/`), so no settings are needed.
- **Vercel:** import the repo. `vercel.json` already publishes only the website files, so no settings are needed.
- **Cloudflare Pages:** import the repo. Leave the build command empty and set the output directory to `/`.
