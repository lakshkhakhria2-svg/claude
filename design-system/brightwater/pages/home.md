# Home page overrides (Brightwater, sample local cleaning service)

| Master rule | Problem (measured) | Override |
|---|---|---|
| White text on CTA `#22C55E` | 2.28:1 | Text `#052E16` on `#22C55E` → 6.54:1 |
| Primary `#0891B2` as text on `#ECFEFF` | 3.54:1 | Small text uses `#0E7490` (5.15:1) |

Anti-patterns: "Hidden pricing" → pricing table on the home page. "Poor before/after imagery" → no stock
photos. The page uses clear illustrated checklists instead until the client supplies real photos.
